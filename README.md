## About this repo

This is also the source for [cargopete.com](https://cargopete.com) - a static
site, no framework at runtime. Built with Astro, deployed on Vercel, apex
`www.cargopete.com`.

`/` is the showcase. `/blog/` is the writing. `/resume/` carries the work history
and the scope panel. The PDF at /resume/petko-pavlovski-resume.pdf is generated by
`yatr resume-pdf` from src/data/resume.ts, the same file the page renders from,
and `yatr ci` fails if the committed PDF and the data ever disagree. There is no
hand-maintained CV: the last one still pointed at a GitHub handle that had moved
on.

### Writing

Posts are Markdown under `src/content/blog/`, one file per post, schema in
`src/content.config.ts`. Frontmatter is `title`, `date`, `description`, optional
`tags`, optional `draft`.

```markdown
---
title: "A title"
date: "2026-09-02"
description: "One sentence. It is the listing subtitle and the feed description."
tags: ["rust", "astro"]
---
```

`draft: true` removes a post everywhere at once - the listing, the feed, the
sitemap and `getStaticPaths` - so it has no URL at all rather than an unlisted
one. Verified by building with a probe draft and grepping `dist/` for it.

Code blocks go through Shiki with two themes and `defaultColor: false`, so every
token carries `--shiki-light` and `--shiki-dark` and the theme picks one. With a
single theme the toggle leaves one set of token colours on the wrong ground.

`/rss.xml` and `/sitemap.xml` are generated endpoints (`src/pages/*.xml.ts`), not
files in `public/`. Both are hand-rolled rather than pulling in `@astrojs/rss`
and `@astrojs/sitemap`: the site has two dependencies and this is forty lines of
XML. The old `public/sitemap.xml` was hand-written, listed the homepage and
nothing else, and would have gone stale the first time a post was added.

### Design

Built to Foundry, the house style shared with Lodestar and nuthatch-indexer.com.
`src/styles/global.css` carries Foundry's `tokens.css` verbatim between two `FOUNDRY`
markers. **Edit those tokens in Foundry and re-copy them here**, never in this repo,
so every site in the house style stays identical. The pre-Foundry token names are
kept as aliases below the block. `src/styles/foundry.css` is Foundry's component
sheet with its font sizes in rem; the root is 112.5% and nothing is sized in px.

Dark, flat: no gradients, no card shadows, hairline borders and whitespace doing the
structural work. Foundry's light values are in the token block, but the site sets no
`data-theme` and has no toggle, so it renders dark.

The hero instrument is Foundry's `ValveRadio`, and its dial reads the number of
published posts, counted from the content collection at build time (drafts are not
posts). The dial runs from 0 to the next multiple of ten above the count. three.js
and `foundry.js` are served from `public/foundry/` and load only when the hero comes
into view; `foundry.js` is copied from Foundry, so re-copy it when Foundry changes.

The index rows on the homepage (`.shelf`) are borrowed from
[learn-thegraph.com](https://learn-thegraph.com), which runs the same house style.
A catalogue reads better as a list of rows with a count on the left than as
another grid of boxes.

The terminal transcript under the stat band is real output, run on 25 September
2026. Both commands can be pasted into a shell and reproduced. If the numbers drift,
rerun them and update the page rather than rounding.

### Develop

```bash
npm install
npm run dev          # http://localhost:4321
npm run build        # -> dist/
npm run check        # Astro types and content, and the resume PDF against its data
```

Or with yatr: `yatr dev`, `yatr build`, `yatr ci`.

After changing `src/data/resume.ts`, run `yatr resume-pdf` and commit the PDF with
it. It prints the page with Playwright's Chromium, which is a one-off
`npx playwright install chromium`; Vercel never runs it, it serves the committed
file.

### Assets

Fonts are self-hosted, subset with `fonttools` to the glyphs the page uses. Together
they are 35KB. Do not add a font CDN. The one heavier file is three.js (600KB),
fetched only when the hero radio scrolls into view.

The favicon set is drawn, not imported. `public/favicon.svg` is the source of truth;
`scripts/make-favicon.py` reproduces the same geometry as PNG and ICO with no
dependencies beyond the standard library. Change both together, then run
`yatr favicon`.
